# DT Sniper 공정성 시연 프로토타입

## 목적

이 폴더는 누적 공정성 기능의 사용자 흐름과 추천 계산을 API 없이 체험하는 독립형 HTML 시연본입니다. 기존 Python 앱과 `web-prototype` 파일을 수정하지 않았습니다.

## 실행

`index.html`을 브라우저에서 엽니다. 외부 라이브러리나 서버 실행은 필요하지 않습니다.

## 시연 순서

1. 기본 참여자 이름과 출발 장소를 살펴보고, 필요하면 추가·삭제하거나 수정합니다.
2. 허용 시간 격차, 이동수단, 장소 유형을 고릅니다.
3. `이동 부담과 누적 공정성 비교`를 눌러 후보별 평균·최장 예상시간, 현재 격차, 첫 도보거리, 환승과 점수를 확인합니다.
4. `공정성 흐름 예시 기록 불러오기`를 눌러 A 참여자가 과거 모임에서 평균보다 더 이동한 상황을 만듭니다. 누적 부담 반영 스위치를 켜고 다시 비교합니다.
5. 후보를 눌러 선택한 뒤 `선택한 후보를 모임 기록에 저장`을 누릅니다. 저장한 예시 기록은 같은 브라우저의 `localStorage`에 남으며, 다음 비교에 반영됩니다.
6. 다시 시작하려면 `모임 기록 초기화`를 누릅니다.

## 공정성 계산의 시연 규칙

- 각 예시 회차에서 참여자별 부담점을 구합니다: 예상시간(분) + 첫 도보거리(m) / 250 + 환승 횟수 × 4.
- 해당 회차의 참여자 평균 부담점을 빼서 개인별 초과·미달 부담을 계산하고, 이를 회차별로 누적합니다. 양수는 그 회차에서 평균보다 부담이 컸다는 뜻입니다.
- 후보별 다음 회차 부담을 누적값에 더한 뒤, 예상 누적 격차를 비교합니다. 추천 점수는 평균 이동시간, 허용 격차 초과분, 최장 퍼스트마일, 환승, 누적 격차를 후보 간 정규화해 계산합니다.
- 공정성 기록이 없으면 누적 격차 항목은 점수에서 제외됩니다. 첫 기록을 저장한 뒤 다음 비교부터 누적 반영을 켤 수 있습니다.

## 데이터와 한계

- 장소명, 지도 모양, 시간, 도보거리, 환승 수는 모두 고정 예시입니다. 실제 장소 검색, 지도 좌표, 대중교통 경로 결과가 아닙니다.
- 입력된 참여자 이름과 출발 장소는 추천 계산에만 표시합니다. 모임 기록은 브라우저의 `localStorage`에 저장되며, 서버나 다른 사람의 브라우저와 공유되지 않습니다.
- 부담점의 환산계수와 점수 비중은 기획 검토용 예시값입니다. 실제 API 결과와 사용자 의견을 바탕으로 조정해야 합니다.
- 실제 앱에 연결할 때는 현재 예시 경로 객체를 주소 검색·대중교통 API의 응답으로 바꾸고, 기록을 서버 저장소로 옮겨야 합니다. API 키는 브라우저 코드에 넣지 않습니다.
