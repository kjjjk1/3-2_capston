프로젝트가 해결하려는 문제

DT Sniper

지도에서 가운데인 장소가 대중교통으로도 모두에게 공평한 것은 아닙니다. DT Sniper는 여러 출발지에서 후보까지의 이동시간, 첫 정류장까지 걷는 거리, 환승 부담을 함께 비교합니다.

사용 흐름

① 참여자와 출발지를 입력합니다.
② 허용 시간 격차와 이동수단을 고릅니다.
③ 후보별 현재 부담과 누적 격차를 비교합니다.
④ 모임을 저장해 다음 장소 선택에 반영합니다.

현재 시연 범위

이 버전은 화면 흐름과 누적 공정성 계산을 체험하는 API 없는 프로토타입입니다. 장소와 이동시간은 예시값이며, 실제 지도 위치나 교통 경로가 아닙니다.

시연 점수 기준 보기

기록이 없을 때는 평균시간 35%, 허용 격차 초과분 25%, 최장 퍼스트마일 20%, 환승 20%로 계산합니다. 기록이 있을 때는 누적 격차에 45%를 반영합니다. 점수는 후보 집합 내 상대값이며 낮을수록 우선입니다. 가중치는 예시값입니다.

화면의 장소와 수치는 모두 시연용 예시입니다. 예상시간이나 실제 위치 정보가 아니며, API를 붙이면 해당 값 영역을 API 응답으로 교체합니다.
