# DT Sniper · 프로토타입 6

`DT_Sniper.html`과 검색용 정류장 데이터 `stops_data.js`가 같은 폴더에 있습니다. 지도와 현재 위치 기능을 사용하려면 프로젝트 루트에서 아래 명령으로 로컬 서버를 실행한 뒤 `http://localhost:8000`을 여세요.

```powershell
python -m http.server 8000 --directory ".\앱 프로토타입 구현(6)"
```

출발 정류장 화면은 OpenStreetMap 타일과 Leaflet으로 구현했습니다. 학교 예시·정류장명 검색·지도 클릭·브라우저 현재 위치를 기준으로 주변 CSV 정류장을 표시하고, 500m 안의 결과가 3개 미만이면 1km로 넓힙니다. 정류장 선택은 목록/지도에서 후보를 고른 뒤 확정 버튼을 눌러야 참여자 출발지에 적용됩니다. 거리는 직선거리입니다. 일반 주소를 좌표로 바꾸는 지오코딩은 아직 연결하지 않았습니다.

브라우저의 현재 위치 기능은 위치 권한이 필요하며, 배포할 때는 HTTPS가 필요합니다. 지도는 Leaflet 1.9.4와 OpenStreetMap 표준 타일을 사용합니다. OSM 표준 타일은 사용량 보장 서비스가 아니며 표시된 저작자 표기와 타일 정책을 따라야 합니다. 실제 공개 서비스에서는 정식 지도 사업자와 타일 사용 조건에 맞게 지도 공급자를 구성하는 편이 적절합니다.

## 정류장 데이터 갱신

프로젝트 루트에 있는 원본 CSV 두 파일을 읽어 정제 CSV, 앱 검색용 JavaScript 데이터, 점검 보고서를 생성합니다.

```powershell
python .\앱 프로토타입 구현(6)\data\clean_bus_stops.py
```

- `data/stops_clean.csv`: 표준 정류장 데이터
- `stops_data.js`: 브라우저 검색 및 선택용 데이터
- `data/cleaning_report.md`: 컬럼·ID·좌표·중복 이름·행정구역 매칭 점검 결과

원본 CSV는 읽기만 하며 수정하지 않습니다. `stop_id`는 위치정보 CSV의 정류장번호입니다. `odsay_station_id`는 별도 필드로 비워 둡니다. ODsay와 연결이 완료되기 전에는 실제 첫 승차 정류장 일치 여부를 판정하지 않습니다.

현재 정류장 검색은 실제 위치 CSV 기반입니다. 경로·시간·노선 수치는 기존 프로토타입의 시연용 예시이며 실제 ODsay 결과가 아닙니다.
