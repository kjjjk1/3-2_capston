이 지도와 후보는 어떻게 만들어졌나요?
후보 생성 과정기획 기준은 사전 등록된 대전 교통거점 20~30곳에서 출발지 범위·노선 연결성·지역 분산을 고려해 10~15곳을 1차 선정합니다.현재 화면은 후보 6곳으로 축약한 시연입니다. 실제 후보 접근성과 ODsay 경로는 API 연결 후 검증합니다.
실제 지도 타일과 ODsay 경로 형상은 연결되지 않았습니다. 확인되지 않은 도로 경로선은 그리지 않습니다.

DT Sniper 소개

만나는 즐거움은 함께.
이동의 부담도 함께.

정류장에서 실제 모임 장소까지의 대중교통 부담을 비교해 만날 곳을 추천합니다.

01 · 정류장 선택

대전 정류장 CSV를 검색용 기준 데이터로 활용합니다. 같은 이름의 정류장은 정류장 ID와 좌표로 구분합니다.

02 · 후보 장소 생성

초기에는 중앙로·대전역·정부청사 등 수동 후보를 비교하고, 다음 단계에서 접근 가능한 교통 거점으로 확장합니다.

03 · 경로·부담 분석

서버에서 ODsay 경로를 조회하고 총시간·도보·환승을 점수화합니다. 실제 승차 정류장이 선택한 정류장과 가까운지도 검증합니다.

04 · 실제 경로 표시

ODsay 응답의 mapObj와 loadLane의 graphPos가 확보된 대중교통 구간만 네이버 지도 Polyline으로 그립니다. 좌표가 없으면 경로선 대신 구간 안내를 보여줍니다.

API 안전 원칙

카카오 장소 검색·ODsay 경로·네이버 지도 렌더링을 연결할 때 비밀 키는 서버에 보관합니다. 이 HTML은 API 키를 포함하지 않는 정적 시연입니다.
