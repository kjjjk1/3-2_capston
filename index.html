이 지도와 후보는 어떻게 만들어졌나요?
후보 생성 과정기획 기준은 사전 등록된 대전 교통거점 20~30곳에서 출발지 범위·노선 연결성·지역 분산을 고려해 10~15곳을 1차 선정합니다.후보 위치와 이 지도는 시연용입니다. 실제 조회는 아래 API 패널에서 선택 후보 하나씩 확인합니다.
실제 지도 타일과 ODsay 경로 형상은 연결되지 않았습니다. 확인되지 않은 도로 경로선은 그리지 않습니다.

이동의 부담도 함께.

정류장에서 실제 모임 장소까지의 대중교통 부담을 비교해 만날 곳을 추천합니다.

01 · 출발 기준 위치

참여자는 학교·동네·지도에서 출발 위치를 정합니다. 정제된 정류장 CSV는 주변 정류장을 참고로 보여주고, 실제 승차 정류장은 경로 API가 찾도록 설계합니다.

02 · 후보 장소 생성

초기에는 중앙로·대전역·정부청사 등 수동 후보를 비교하고, 다음 단계에서 접근 가능한 교통 거점으로 확장합니다.

03 · 경로·부담 분석

서버에서 ODsay 경로를 조회하고 총시간·도보·환승을 점수화합니다. API가 제안한 첫 승차 정류장과 출발 기준 위치의 접근성도 확인합니다.

04 · 실제 경로 표시

ODsay 응답의 mapObj와 loadLane의 graphPos가 확보된 대중교통 구간만 네이버 지도 Polyline으로 그립니다. 좌표가 없으면 경로선 대신 구간 안내를 보여줍니다.

API 안전 원칙

Kakao Local·ODsay 비밀 키는 server.py의 서버 환경변수로 관리합니다. Naver Maps 클라이언트 ID는 브라우저에서 쓰이므로 Naver Cloud Console에서 허용 도메인을 제한해야 합니다.
