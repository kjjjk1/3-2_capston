# DT Sniper 브라우저 전용 보완본

## 실행

GitHub Pages 같은 HTTPS 정적 호스팅에 이 폴더의 내용물을 올립니다. ZIP 자체를 올리지 말고 index.html과 JS/CSS 파일들이 같은 위치에 있도록 배치합니다. Render 설정이나 DB 접속 정보는 필요하지 않습니다.

PC에서 미리 확인하려면 Python이 설치된 상태에서 start-browser-demo.cmd를 실행하고 http://127.0.0.1:8765/ 를 엽니다. 이 프로그램은 정적 파일만 제공하는 로컬 미리보기 도구이며 기존 Render API 서버가 아닙니다. index.html 더블클릭(file://)은 지원하지 않습니다.

## 기존 서버 종료 전

1. 기존 Render와 Supabase가 켜진 상태에서 이 버전을 엽니다.
2. 모임 화면 아래 `서버 종료 전 기존 모임 가져오기`를 펼칩니다.
3. 기존 모임 링크 또는 방 ID를 입력하고 가져오기 버튼을 누릅니다. 이때만 서버의 모임/기록 GET 요청을 보내며 경로 API는 호출하지 않습니다.
4. 가져온 모임의 참여자·출발지·이동 기록을 확인합니다. 서버 사진은 복사하지 않습니다. 서버가 출발지 조회를 허용하지 않으면 가져오기를 중단하고 안내합니다.
5. `기록 백업 내려받기`로 JSON을 따로 보관합니다.
6. 같은 주소를 새로고침하여 기록이 남는지 확인한 뒤 Render 중지를 진행하세요. 이 패키지는 서버를 자동 중지하거나 클라우드 기록을 삭제하지 않습니다. Supabase 삭제 전에는 별도 DB 백업도 권장합니다.

## 다른 기기 또는 브라우저로 이동

기존 브라우저에서 백업을 내려받고 새 브라우저에서 `백업 파일 가져오기`로 불러옵니다. 모임 링크만 공유해서 데이터가 전송되지는 않습니다. 백업에는 참여자 이름·출발지·기록이 포함되지만 접속 토큰·복구 코드는 포함하지 않습니다. 가져올 때 브라우저용 권한을 새로 만듭니다. 같은 ID의 모임이 이미 있으면 덮어쓰지 않고 전체 가져오기를 중단합니다.

저장 영역은 브라우저 프로필과 사이트의 출처(프로토콜/도메인/포트)에 종속됩니다. localhost와 127.0.0.1, 다른 포트, GitHub Pages와 로컬 미리보기의 저장소는 서로 다릅니다. 사이트 데이터 삭제·시크릿 창 종료·브라우저 저장 정책 등에 의해 데이터가 없어질 수 있으므로 JSON 백업을 별도로 보관하세요. 저장 공간 영구 보관 요청이 항상 허용되는 것은 아닙니다.

## 유지 및 보완 범위

- 자체 추정 분석, 정기 모임 누적 부담, 신규 참여자 0 시작, 1회 재탐색, 장소 확정 및 이동 기록 저장 유지.
- 기본 추천은 누적 표준편차 우선입니다. 서버 버전과 API 시간이 같다는 의미는 아니며 매회 개선은 보장하지 않습니다.
- 분석은 Web Worker에서 수행하여 주 화면 정지를 줄입니다. Worker 미지원 환경에서는 메인 스레드 분석을 사용합니다.
- IndexedDB 저장, 모임 이름 수정, 이 브라우저에서 모든 참여자 관리, JSON 백업/복원, 서버 기록의 명시적 1회 가져오기 추가.
- Web Locks 지원 브라우저에서는 탭 간 저장 작업을 직렬화합니다. 미지원 브라우저에서는 여러 탭을 동시에 수정하지 마세요.
- 브라우저 전용 묶음이므로 어느 정적 호스트에서 열어도 클라우드 API 분석은 하지 않습니다. localhost와 Pages에서 같은 내부 저장 모드를 사용합니다.
- 평소 앱 데이터의 서버 요청은 차단하지만, 지도 라이브러리/타일 다운로드 및 사용자가 누르는 외부 지도·공유 링크에는 인터넷이 필요합니다. 완전 오프라인 PWA는 아닙니다.
- 개발자 도구를 사용하는 동일 기기의 사용자는 브라우저 데이터를 수정할 수 있습니다. 서버 권한 보안과 같은 모델이 아니라 개인 시연용 저장 방식입니다.

## 검증

자동 검증: 모임 생성/참여자 등록/이름 수정/분석/확정/누적 기록/재탐색/저장 어댑터 재접속/JSON 내보내기·가져오기/중복 충돌/잘못된 파일의 무변경/localhost·Pages API 어댑터/정적 파일 참조 검사 통과.
실제 브라우저: 예시 4명 생성 → Web Worker 분석 → 확정 → 새로고침 후 IndexedDB 기록 유지 → JSON 다운로드 및 토큰 미포함 확인 완료.
실제 서버 데이터 가져오기, GitHub Pages 배포 및 다른 기기에서의 파일 가져오기는 이번 작업에서 수행하지 않았습니다.

검증 코드는 상위 output/browser-demo-verification.mjs에 있으며 Node.js 22 이상에서 `node --test output/browser-demo-verification.mjs`로 실행합니다.
